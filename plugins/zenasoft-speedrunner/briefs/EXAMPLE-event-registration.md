# Brief: Hybrid Workplace Trends Webinar

## Brand

DeskFlex

## Page purpose

Registration page for a live webinar. Target audience: office managers and
workplace coordinators considering desk booking software. Goal: collect
registrations via the form.

## Design reference

Two-column layout. Left side: event details, speakers, agenda. Right side:
registration form card (sticky on desktop, stacks below on mobile). Professional
but not stiff — this is an educational event, not a sales pitch.
