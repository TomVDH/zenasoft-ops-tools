# ZenaSoft Ops Tools

Claude Code plugins for ZenaTech marketing. Internal tooling, published here so teammates can install without an account.

## Install, once

```
claude plugin marketplace add TomVDH/zenasoft-ops-tools
claude plugin install zenasoft-speedrunner@zena-claude-plugins
```

Restart Claude Code, then type `/speedrun-help`.

## Update

```
claude plugin marketplace update zena-claude-plugins
claude plugin update zenasoft-speedrunner@zena-claude-plugins
```

Then restart Claude Code.

## Plugins

| Plugin | What it does |
|---|---|
| `zenasoft-speedrunner` | Builds a branded landing page or a simple email from a marketer's brief. `/page-speedrun`, `/email-speedrun`, `/speedrun-help`. |
